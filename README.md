# 🎬 Netflix Movies Analysis Using Python

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a Netflix movies dataset using Python.

The objective is to explore Netflix's movie catalog, understand patterns in movie releases, genres, ratings, duration, countries, and other attributes, and generate meaningful insights through data analysis and visualization.

---

## 🎯 Objectives

* Analyze the Netflix movie dataset
* Clean and preprocess the data
* Explore movie genres and ratings
* Analyze movie releases over the years
* Identify popular and frequently occurring genres
* Analyze movie duration
* Explore country-wise movie distribution
* Visualize important patterns and trends
* Generate meaningful insights from the data

---

## 🛠️ Technologies & Libraries

* **Python**
* **Jupyter Notebook**
* **Pandas**
* **NumPy**
* **Matplotlib**
* **Seaborn**

---

## 🔄 Project Workflow

### 1. Data Loading

Loaded the Netflix dataset using Pandas and explored its structure, columns, and data types.

### 2. Data Cleaning

Performed data preprocessing including:

* Handling missing values
* Removing duplicate records
* Checking data types
* Cleaning categorical columns
* Handling inconsistent or missing information

### 3. Exploratory Data Analysis

Analyzed different aspects of the Netflix movie catalog, including:

* Movie genres
* Ratings
* Release years
* Movie duration
* Countries
* Directors and cast
* Content distribution

### 4. Data Visualization

Created visualizations using **Matplotlib and Seaborn**, including:

* Bar charts
* Line charts
* Count plots
* Histograms
* Box plots
* Heatmaps

### 5. Insights Generation

Derived meaningful insights from the analysis to understand trends and characteristics of movies available on Netflix.
